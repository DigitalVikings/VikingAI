# Changelog

All notable changes to **VikingAI** will be documented in this file.

## [0.1.0] - 2026-10-25

### Added
- **2.5D Clearance Navigation Graph**: Unified spatial navigation overcoming vanilla pathfinding tile seam boundaries and ledge drops.
- **Tactical Context Steering & Locomotion**: 16-ray obstacle avoidance, 360-degree combat strafing, polar follower formations, and friendly door traversal.
- **Sensory Perception & Cover Sampling**: Line-of-sight awareness cones, hearing attenuation through structures, and dynamic environmental cover evaluation.
- **Pack Combat Coordination**: Dynamic attack token distribution preventing unnatural enemy swarming and synchronizing tactical flanking.
- **Settlement Affordances & Smart Objects**: Shared reservation system for workstations, doors, chests, and beds preventing NPC interaction deadlocks.
- **Humanoid NPC Factory & Unloaded Simulation**: Standalone Norse NPC builder with custom appearance options, persistent equipment, and unloaded-zone virtual agent simulation.
